# Mawhiba Quest

A daily practice app for the Mawhiba Level 1 (English) test on November 12, 2026.

- Daily 10-question mission that follows a 40-day plan
- Practice rounds for Math & Spatial, Mental Flexibility, Verbal, and Science & Mechanics
- Timed 20-question mock test with full review
- Progress, streaks, and badges, synced between family phones with Firebase Firestore
- Works offline too, and syncs again when the internet returns

Open the app: https://bukhaa0s-cyber.github.io/mawhiba-quest/
